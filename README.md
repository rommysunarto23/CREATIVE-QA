## Portfolio Principle

The goal is not to collect isolated AI-generated images. Each project is treated as a small commercial campaign with:

- a defined creative brief and visual system;
- prompt development and iterative refinement;
- product or character continuity requirements;
- visual QA and explicit accept/reject decisions;
- final asset selection and campaign-role planning.

## Selected Capabilities

**Generative visual production:** photorealistic image generation, visual continuity, composition, lighting, material fidelity, product/character consistency.

**Creative QA:** anatomy and artifact review, packaging/branding consistency, reference matching, select/reject rationale, iterative correction.

**Workflow thinking:** structured documentation, repeatable production processes, AI-assisted tooling, and automation-oriented creative workflows.
